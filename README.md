# 🐾 PetMatch - Conectando Corações e Patas

Plataforma web para adoção de animais de estimação, conectando adotadores com ONGs de forma segura e responsável.

## 📋 Funcionalidades

### Para Adotadores
- ✅ Cadastro e login
- ✅ Visualizar pets disponíveis
- ✅ Filtrar por tipo, tamanho e localização
- ✅ Adicionar pets aos favoritos
- ✅ Solicitar adoção
- ✅ Perfil com upload de fotos e vídeos da residência
- ✅ Acompanhar solicitações de adoção

### Para ONGs
- ✅ Cadastro e login
- ✅ Painel administrativo
- ✅ Gerenciar pets (adicionar, editar, deletar)
- ✅ Visualizar solicitações de adoção
- ✅ Aprovar ou rejeitar solicitações
- ✅ Agendar visitas pré-adoção
- ✅ Dashboard com estatísticas

### Geral
- ✅ Design responsivo (mobile, tablet, desktop)
- ✅ Paleta de cores azul e verde
- ✅ Animações suaves
- ✅ Carrossel de histórias de sucesso
- ✅ Depoimentos rotativos
- ✅ Contadores animados com porcentagens
- ✅ Funciona 100% offline

## 🚀 Como Usar

### 1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/petmatch.git
cd petmatch
```

### 2. Abra no navegador
Simplesmente abra o arquivo `index.html` no seu navegador favorito.

**Ou use um servidor local:**
```bash
# Com Python 3
python -m http.server 8000

# Com Node.js
npx http-server

# Com VSCode Live Server
Clique direito em index.html > Open with Live Server
```

### 3. Acesse em
```
http://localhost:8000
```

## 🔄 Fluxo de Uso

### Como Adotador
1. Clique em "Entrar"
2. Selecione "Adotador"
3. Faça login ou cadastro
4. Explore pets disponíveis
5. Clique em "Quero Adotar!"
6. Acompanhe sua solicitação

### Como ONG
1. Clique em "Entrar"
2. Selecione "ONG"
3. Faça login ou cadastro
4. Acesse o Painel ONG
5. Gerencie seus pets
6. Aprove/rejeite solicitações

## 💾 Dados

Todos os dados são armazenados em **localStorage** do navegador. Isso significa:
- ✅ Funciona 100% offline
- ✅ Dados persistem entre sessões
- ✅ Sem necessidade de servidor
- ⚠️ Dados são perdidos se limpar cache do navegador
